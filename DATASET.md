# Pregenerated Dataset

A corpus of **10,000** independent simulated Type 1 Diabetes patient trajectories, each **55.5 h** (≈ 2.31 days) of post-warmup CGM at 5-minute cadence (**666 steps**; the first 48 h of warmup are discarded before caching). Channels are stored as per-channel blosc2 NDArray (`.b2nd`) files with a byte-shuffle filter and zstd-5 compression.

This file is generated by `cache_simulator.py` while the dataset is built; the figures below are computed over every cached trajectory.

## Generation parameters

| Parameter | Value |
|---|---|
| Post-warmup window | 55.5 h (666 steps) |
| Warmup discarded | 48.0 h |
| Seed salt | 42 |
| Rail filter | discard bg_observed ≥ 399 or ≤ 41 mg/dL |
| Hypo oversampling | prob 1, ≥ 5.00% of time < 70 mg/dL |
| Rejection cap | 50 attempts/row (soft) |
| Compression | blosc2 zstd-5 + byte-shuffle, 32 rows/chunk |

### Sampling

- Trajectories simulated: 42,958 for 10,000 kept rows (accept rate 23.28%, mean 4.30 attempts/row).
- Every stored row is rail-valid; hypo-designated rows: 10,000 (10,000 met the hypo target within the soft cap).
- Hypo rows kept below target (soft-cap fallback): 0.

## Method

Patient count, durations, CGM-hours and disk footprint are exact (metadata + on-disk file sizes). Carbs and insulin are integrals of the per-step carb-appearance and insulin-delivery channels, so their sums read as grams appeared and units dosed; the basal/bolus split is exact because the two are summed from separate channels. The carb-appearance trace folds meal, hypo-rescue, and follow-up carbohydrate into one channel, so the carb-appearance-event count (upward threshold-crossings > 1 g/step, 30-minute refractory) is an upper bound on discrete meals. The discrete bolus count merges boluses whose pharmacokinetic tails overlap and is therefore a lower bound. Glycemic-band shares are computed over the pooled `bg_observed` readings.

## Reproduce

```bash
python cache_simulator.py --out-dir cache --pool-size 10000 --sim-hours 55.5 --warmup-hours 48 --hypo-oversample 1 --hypo-min-frac 0.05 --seed-salt 42
```
